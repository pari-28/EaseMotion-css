# Draw Border Line Checkout Popover

A responsive **Draw Border Line Popover** designed for e-commerce checkout interfaces using only HTML and CSS.

## Features

- Pure HTML & CSS
- Responsive design
- Keyboard accessible
- Animated border drawing effect
- CSS custom properties
- Supports `prefers-reduced-motion`
- No JavaScript

## Files

- demo.html
- style.css
- README.md

## Usage

Open `demo.html` in any modern browser.

## Customization

Modify the CSS variables inside `:root` to change colors, border radius, spacing, and animation timing.
